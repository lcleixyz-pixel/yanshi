## 审查中解决的问题

- 棱镜组中心线原本经过顶棱，已调整几何；逐块检查中心线穿过两个面的内部。这只是几何相交检查，不是色散光线追迹或实测校准。
- 棱镜观察端随调焦套筒移动；光栅式固定构型保留；展开位移与真实机械自由度分别记录。
- 折射仪测台有真实通孔，盖子改为中空连续曲面，内部标尺保留在机内。
- 显微镜光阑叶片与操纵环分开。叶片是固定开度示意，`controlAngleChangesAperture:false`；旋转操纵环尚不驱动开度动画。
- 分光镜目口近景暴露共面内壁和端面UV问题，修正连续截面与UV映射后再做浏览器检查。
- 审阅工具修正窄视场展开适配、嵌套部件隔离与复位，避免展开裁切或选中子部件后消失。
- 元数据统一明确静态结构不等于光学模拟，避免下游将结构示意误当测量或模拟结果。

独立复核保留在 [independent-structure-review.md](../gem-lab/assets-source/instruments-2026-10-07/independent-structure-review.md)，包含发现、修正和关闭依据。

## 重建与保存

正式脚本位于 `gem-lab/tools/3d-assets/`：

- `blender/build_spectroscopes.py`：用 `-- --instrument prism-spectroscope` 或 `grating-spectroscope`。
- `build_refractometer.py`：折射仪，`-- --render` 同时生成渲染。
- `build_gem_microscope.py`：显微镜，`-- --candidate <原始候选路径> --render` 将原始候选藏入母版参考集合并渲染。
- 配套 inspect / verify / render / compose 脚本与 `verify-instruments.mjs` 提供检查和复核。

使用本机 Blender 5.2、现有 Three.js 与 glTF Validator，参考拼图依赖 Pillow。脚本从自身位置定位工作树，不要求主项目目录参与重建；运行方式详见逐台 README。恢复完整来源、原候选、母版与对照图须保留 `assets-source/`；分光镜重建需要其 `references/sources.json`。只 clone Git 不能恢复全部源档案，导出元数据的时间/顺序也不承诺二进制字节级重复。显微镜 provenance 是本次验收记录；未来修改模型后须同步刷新其中的哈希与验证结果。

网页资产、脚本与本记录进入本地 Git；大体积母版、原图、Tripo候选及浏览器证据仍留本工作树被忽略的 `assets-source/`。**本轮没有创建异机或网盘备份。**不要将工作树删除当作归档完成。
