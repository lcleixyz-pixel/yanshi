## 一、分光镜

### 主要素材：《常见宝石特征吸收光谱》（用户 10-08 提供，并确认图片可信）

- 原件：`~/Downloads/特征吸收光谱(1).doc`，以及用户用 WPS 另存的 `.docx`。
- 项目内副本：`gem-lab/assets-source/spectroscope-reference/2026-10-08-特征吸收光谱/`。该目录被 Git 忽略，不进 `public/`。里面有：
  - `images/` 下 58 张原图；
  - `index.json`：59 条对应关系，包括图片、品种、原文波长描述、SHA-256，以及对应的项目样品 ID；
  - `sheet0–2.png`：缩略图总览。
- **内容**：59 个品种条目，每条都有一张吸收光谱示意图和一段波长文字。示意图是绘制的，不是实拍照片，按棱镜式的非线性刻度画成：700→400 nm，红端压缩、紫端展开，与棱镜式分光镜看到的样子一致。
- **对应规则**：文档中每张图都排在它所属品种文字的前面。`image22` 被“暗绿色水钙铝榴石”和“水钙铝榴石”两个条目共用。抽查了红宝石、碧玺、铁铝榴石、海蓝宝石、坦桑石、祖母绿、橄榄石、变石、变色蓝宝石、榍石、绿帘石、菱锰矿，图和文字都对得上。
- **能覆盖的项目样品**：18 条对应到 15 个样品，即红宝石、碧玺、尖晶石、蓝宝石、海蓝宝石、坦桑石、祖母绿、橄榄石、翡翠、锆石、钻石、欧泊、绿松石、葡萄石、石榴石。
- **使用口径**：
  - 图片可以作为棱镜式的参考视图；
  - 光栅式是线性刻度，要按图上的刻度把图片换算到线性坐标，或者用波长数据重新绘制，不能直接拿棱镜式的图来用；
  - 波长数据仍要与下列来源交叉核对。

### 交叉核对来源（按优先级）

1. **国家标准 GB/T 16553《珠宝玉石 鉴定》**：各品种的吸收光谱特征，使用前先确认现行版本。
2. **GIA Gems & Gemology 和 GIA 宝石百科**：用于核对机型说明和光谱照片。手持光栅分光镜为固定焦距、固定狭缝（[GIA 产品说明](https://store.gia.edu/products/diffraction-grating-spectroscope)）。
3. **本机 GemKB 已入库的教材条目**：例如《系统宝石学》，作为第三方佐证。

### 条件不合适时的对照：先用合理模拟（用户 10-08 确认）

条件不满足时的对照照片很难拍到，课程先用模拟。原则是：参考光谱只用一份，就是这份资料的图片和波长数据；条件变化只作为“显示时的变换”叠加上去，不另画一套假光谱。页面上标明“教学模拟”。

| 条件 | 模拟方式 | 学生应该看出的变化 |
|---|---|---|
| 合适设置 | 相距不到 3 nm 的细线显示为一条细线（2026-10-09 用户确认） | 红宝石 694 / 692、476 / 475 各看到一条细线，与手持分光镜实际观感一致 |
| 狭缝过宽 | 按狭缝宽度对谱线做模糊，并降低对比度 | 相距更远的细线也并成模糊的带（如红宝石 668 / 659），弱线先消失 |
| 狭缝过窄 | 整体变暗、噪声增大，紫端先暗下去 | 亮度不够，弱吸收线和蓝紫区的特征看不清 |
| 焦距偏离（仅棱镜式） | 模糊程度随偏离量增大 | 所有特征都发虚，回到正确焦距后恢复清晰 |
| 透过样品的光太弱（深色或很厚的样品） | 整体变暗，蓝紫端先变黑 | 不能把“暗”误认为“吸收”；应换照明或换方向 |
| 光没有穿过样品（白光直接进入） | 显示无吸收的连续光谱 | 看到连续光谱，不等于样品没有吸收特征，先检查对光 |
| 光栅式 | 狭缝和焦距固定，只有对光位置和光强会变；整体比棱镜式暗 | 光栅式没有狭缝和焦距可调，排查思路与棱镜式不同 |

- 特征消失的先后，按数据里的强、中、弱标注计算，弱的先消失。
- 每种条件的参数和效果写成单元测试。例如：“合适设置下 694 / 692 只画成一条细线”；“狭缝过宽时 668 / 659 并成模糊的带”；“恢复正确设置后显示与参考光谱一致”。浏览器测试另查画面：画出的细线互不重叠。
- 2D 演示里已经有一套噪声模型（`SpectroscopeDemo.tsx:179-183` 的狭缝、焦距和光栅惩罚项），可以参考它的参数，但要改成上面这种“变换”的写法，并修正光栅式也有狭缝和焦距的问题。
- 以后拿到实拍对照照片，再逐项替换模拟效果，并注明出处。
