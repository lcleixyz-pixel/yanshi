# 新仪器 3D 资产 · 第 3 轮修改说明（交给 Codex）

2026-10-07。依据用户第 3 轮意见与 Claude Code 资料核对。沿用第 1、2 轮的工作位置、交付格式、技术要求与边界；Tripo 累计 275 / 2000，本轮**不需要云生成**。

**执行分工**：Codex 沙箱内 Blender 会在 Metal 初始化时崩溃（第 2 轮已确认）。本轮请 Codex **只修改构建脚本、manifest 规则、校验脚本与审阅工具，并做静态 / 数学检查**，不要尝试运行 Blender。完成后在制作记录写清需要执行的命令；由 Claude Code 在可用终端中运行 Blender、`verify-instruments.mjs --round3` 和浏览器检查。

## 一、白色折射仪

1. **删除机身侧面的 5 个圆点**（用户确认不需要用途不明的装饰）。manifest、provenance、校验脚本中的相应项目同步删除。
2. **翻盖改为盒形盖**：有侧壁和深度，前沿带斜面，内侧白色；铰链与可见的铰链螺钉在后上方，照项目原图。
3. **测台**：不锈钢测台坐在一级白色台阶上，尺寸收小到原图比例；中央的棱镜窗口（半圆柱棱镜的平面）明显可见，为深色玻璃条；去掉测台前缘下方露出的黑缝。
4. **目镜**：较粗的黑色滚花筒，能看到凹入的镜片和侧面小螺钉；可拆偏光片作为套在目镜外侧的独立圆片保留。目镜沿自身轴线可滑动调焦（manifest 给出平移范围，示意即可）。
5. **内部光路核对与修正**（最重要）。依据 [Gemology Project：Refractometer](http://gemologyproject.com/wiki/index.php?title=Refractometer)（基于 Eickhorst SR 0.005 剖面）与 [Course: Total internal reflection](https://gemologyproject.com/wiki/index.php?title=Course%3ATotal_internal_reflection)，标准光路为：

   **后部进光 / 内置光源 → 第一反射镜 → 半圆柱棱镜中心（宝石接触面）→ 反射光 → 标尺 → 透镜（组）→ 第二反射镜 → 目镜（可滑动调焦，偏光片套在目镜上）**

   现有模型只有后部光源、半圆柱、一个合并的「标尺 / 反射镜」和目镜，缺第一反射镜和透镜组，标尺与第二反射镜合并，也没有光线路径检查。请改为以下独立部件（全部在机内，`internalOpticsIllustrative: true`）：
   - 内置光源（后部，示意钠黄光 589 nm 的 LED；内置光源型号见 Gemology Project 品牌说明：Eickhorst、Krüss 有内置照明款）
   - 第一反射镜
   - 半圆柱棱镜（高折射率玻璃，示意 n ≈ 1.88，资料中常为 Schott N-LaSF；轴线沿机身宽度方向，平面即测台窗口）
   - 标尺（透明分划板，刻线示意）
   - 透镜组（1–2 片示意）
   - 第二反射镜
   - 目镜、偏光片（外部件，见上）

   **几何检查**：以接触面法线为基准，主光线入射角取约 60°，并给出一扇示意光线，覆盖资料中常见读数范围的临界角：θc = arcsin(n_stone / 1.88)，n_stone 为 1.35–1.80 时约 46°–73°。光线须依次命中：光源 → 第一反射镜 → 半圆柱中心（入射、反射都过圆心，在曲面上垂直穿过）→ 标尺 → 透镜 → 第二反射镜 → 目镜轴线。各段不被外壳或其他部件遮挡。结果写入 `refractometer-optical-path-check.json`。
   - 在 GLB 中加入一个默认隐藏的「光路示意线」节点（细折线 + 光线扇），供以后网页讲解光路时打开。
   - 这是几何示意检查，不是读数仿真；不要声称刻线位置已校准。

## 二、棱镜式分光镜

3 块 Amici 棱镜（冕–火石–冕）要能分辨：显示两条胶合斜界面；冕牌与火石用轻微不同的透明度 / 色调（火石略带黄色、折射率更高）；斜面方向符合直视棱镜的交替排列。其余保持第 2 轮。

## 三、宝石显微镜

1. **载物台保持长方形**（用户确认），不再改成梯形。
2. **立柱**：做出 C 形镜臂的轮廓（后部立柱 + 上方向前伸出的托架），不再是方块。
3. **箱式顶灯从侧面移到正前方**：灯头位于物镜前方、略高于载物台，朝下约 45° 照向样品位置；鹅颈从载物台前缘（或底座前部）伸出。要求：不挡住物镜到样品的光路、不挡住目镜视线，也不和宝石夹相撞。manifest 给出灯头朝向。
4. **光阑**（用户确认现有设计是对的，在此基础上优化）：叶片边缘倒角，用深色哑光金属；开合全程叶片不穿插、孔径单调变化（沿用第 2 轮的形态目标检查）；操纵环加一个小拨杆，方便抓取和识别转动方向；最小 / 最大孔径保持约 7.5 / 40 mm，与转角的映射写入 manifest。
5. **底部光源结构**（重点）：要能在网页里实现多种照明方式。依据 [Gemology Project：Microscope](https://gemologyproject.com/wiki/index.php?title=Microscope) 和 [GemologyOnline 关于暗域 / 亮域底座的讨论](https://www.gemologyonline.com/Forum/phpBB2/viewtopic.php?t=6477)：

   底座内的结构自下而上为：
   - **底光光源**（LED / 卤素灯示意，独立自发光网格，可单独开关）
   - **反射碗**（椭球面反射器：光源在一个焦点，样品位置在另一个焦点）
   - **暗域挡板**（中央不透明圆片，挡住光源直射物镜的光线）+ **亮域拨杆**：拨杆转动或推动挡板，让开中央，切换为亮域透射光（资料指出碗内反射光仍会叠加，manifest 照实注明）
   - **光阑**（已有）
   - **漫射板**：磨砂白板，可从侧面推入 / 转入，盖在光井上方
   - **起偏片**：可推入，放在光阑上方；**检偏片**：可装在物镜下方的夹片

   台面以上：顶灯（见第 3 条）、光纤鹅颈（斜射 / 水平光），各自的出光端都做成独立的自发光网格。

   manifest 增加 `illuminationModes`，逐一列出每种方式需要的部件状态（光源开关、挡板开 / 合、光阑开度、漫射板、起偏片、检偏片），供网页一键切换：

   | 方式 | 部件状态 |
   | --- | --- |
   | 暗域 darkfield | 底光开；挡板合；光阑开 |
   | 亮域 brightfield | 底光开；挡板开 |
   | 点光源 pinpoint | 亮域 + 光阑接近最小 |
   | 漫射 diffused | 亮域 + 漫射板推入 |
   | 偏光 polarized | 亮域 + 起偏片推入 + 检偏片装上 |
   | 遮光 shadowing | 亮域 + 光阑部分关闭（示意遮光片可选） |
   | 顶光 overhead | 底光关；顶灯开 |
   | 斜射 / 水平 oblique | 底光关；光纤开，出光端朝向样品侧面 |

   **几何检查**（写入 `microscope-illumination-check.json`）：暗域时，挡板完全挡住从光源到物镜入口的直线；反射碗反射的光线以斜角到达样品位置，落在物镜接收锥以外。亮域时，挡板让开中央光路。漫射板、起偏片推入后完整覆盖光井；推出后不进入光路。顶灯与光纤的出光方向都指向样品位置。只做几何示意，不做照度模拟。
