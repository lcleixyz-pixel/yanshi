## 目标

把 `/explore/optics/refractometer` 从“结构 + 固定光路案例”做成一节约 9 分钟、可以完整验收的**基础读数课**：认识部件 → 理解光路 → 开灯放样 → 接触条件（含一次接触不良的恢复练习）→ 观察并输入读数 → 换方向复核 → 解释 → 清理复位。

教学方式沿用偏光镜课程：同一份课程状态同时驱动 3D 模型和读数窗口；学生先操作、先填写，系统再给出参考答案和解释；条件不对时说明原因和恢复办法。

## 课程样品

采用**尖晶石**（`samples.ts` 的 `spinel`，刻面，均质体，RI 1.718，低于接触液上限）。均质体只有一条边界，换方向后边界不动，适合第一套基础课。双折射、点测和超量程放到后续课程。

### 2. 课程状态与规则：`domain/refractometerCourse.ts`（纯函数，可单元测试）

- 课程状态至少包括：电源、翻盖、接触液（`none` / `drop`）、样品（`none` / `placed`）、接触（`good` / `air-gap`）、当前样品方向、学生读数记录、清理项。
- 写一个派生函数（名称自定），输入课程状态，输出：
  - 3D 案例 ID 和部件显隐；
  - 2D 读数视图（沿用 `RefractometerView`）；
  - `validReading: boolean`；
  - 不能读数时的原因和恢复办法（文字放进规则表，不要散落在页面里）。
- 硬规则：
  - 只有电源打开、有接触液、样品已放、接触良好时，`validReading` 才为 true；
  - `validReading` 为 false 时，输入框不能提交数值，只能记为“无法可靠读数”，并显示原因；
  - 3D 案例的 `readout.sampleRI` 与 2D 窗口边界对应的 RI 必须来自同一样品数据，用单元测试锁定。
- 课程步骤与检查清单的写法仿照 `polariscopeCourse.ts`：

| 步骤 | 内容 | 完成条件 |
|---|---|---|
| parts | 认识部件 | 至少点过测台棱镜（接触窗口）、内部光源、刻度、目镜、翻盖、接触液 |
| path | 理解光路 | 打开光线并完整看过光路一遍；答对“明暗边界从哪里来”1 题 |
| prepare | 开灯与放样 | 开电源后先看到只有刻度的视场；滴一小滴接触液；把样品台面朝下放到窗口中部 |
| contact | 接触条件 | 课程固定先进入 `air-gap`：视场里没有边界；学生选出原因（如缺少光学接触或接触液不足），执行恢复动作（补液或轻推贴合）后进入 `spinel-good` |
| observe | 观察读数 | 学生输入读数**之后**才显示参考值和偏差，用 `checkRI` 的刻面法判定 |
| verify | 换方向复核 | 把样品转到另一个方向再读一次，学生回答“边界是否移动、说明什么” |
| explain | 解释 | 2–3 道问答：临界角与边界、空气间隙为什么读不出、接触液上限的含义 |
| cleanup | 清理复位 | 取下样品、擦净测台和样品、关闭电源、合上翻盖 |
