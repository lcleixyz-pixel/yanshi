# 偏光镜 · Tripo / Meshy 对照输入包

准备日期：2026-10-05。建议先选一个工具，分开做 A、B 两次生成，各一次。两组尽量采用相同模型版本、几何质量、纹理质量和增强设置；先看结果再决定是否追加。

## 上传哪些文件

| 任务 | 输入文件 | 操作 |
| --- | --- | --- |
| A · 原图单图 | `A-original/01-original.png` | 选择单图生成，只上传这一张；它是项目原图的原样副本 |
| B · 一致四视图 | `B-multiview/01-front.png`、`02-left.png`、`03-back.png`、`04-right.png` | 选择多视图生成，按文件名对应正、左、后、右视图槽 |

B 图基于同一个三维结构重新设置中性灯光与材质渲染，采用同一比例、机位仰角和画幅，便于检查部件是否相互对应。不是把原来的黑背景展示图直接拿来上传。未实测的背面仍是建模假设，没有增加电源插孔、铭牌或内部机构。

`review/` 内的主视、俯视和 imagegen 材质目标图用于审阅，**不要与 B 组四张图片混传**。HTML 总览也不能作为拼图上传。

## 工具中的设置

- **Tripo**：按 front / left / back / right 对应上传。若当前网页界面只开放部分视图，按实际槽位上传匹配图片；不要把背面冒充侧面。原图单图 A 与四图 B 要建立两个任务。
- **Meshy**：把 `01-front.png` 放在第一张，其余三张作为补充角度。原图 A 单独建任务。
- 若界面提供纹理和 PBR，首轮保留；暂不追求极低面数。没有的选项不必寻找 API 参数来替代。
- 首轮先比较整机外观；生成后再整理独立部件。Tripo H 系列 API 的分件生成与纹理/PBR 存在组合限制，不能把“可分件”和“完整材质”当作任意可叠加选项。
- 保留原始高模，再另做减面或重拓扑；优先导出 **GLB**，并另存可下载的全部材质贴图。若没有 GLB，可保留 OBJ/FBX 与完整贴图目录。

这里核实的是官方 API 文档中的能力。Studio 网页的按钮名称、套餐、可用模型和参数可能不同，以你登录后的实际界面为准。不要为了与本文文字一致而购买新的套餐。

## 生成后怎么判断

在平台旋转看四面，检查：

1. 白色折板是否仍然薄而连续，底座宽厚比例是否接近参考图。
2. 上下镜环的通光区域有没有被填平、封死。中心应保留薄光学片，不能生成厚实盖板，也不要把镜片直接删成空洞；发亮的圆面本身不能证明孔洞封死，需要转到侧面检查厚度。
3. 载物台和上下环的边界是否清晰，相邻层有没有粘成一块。
4. 左侧干涉球、支杆和脚垫是否保留，是否凭空增加了零件或背面接口。
5. 模型转到侧面、背面时是否仍成立；不要只比较平台的默认灯光预览。

请保留每组的任务 ID、模型版本、设置截图、消耗积分和原始下载包。完成后把 A、B 的 GLB 与贴图交给 Codex，即可继续比较、修复、整理转轴和接入当前教学页面。原来的可操作模型仍保留，生成模型不会自动替换它。

这两组用于比较哪条制作路线的产物更适用。由于图像来源、分辨率和已有几何信息同时不同，不能仅凭两次结果就认定“多视图一定优于单图”。
