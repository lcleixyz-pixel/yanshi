# 仪器交互与体验统一规划（2026-10-10）

用户要求：参考已完成的偏光镜，考虑交互便利与用户体验，各仪器保持一致的风格，规划后推进。

## 一、口径

- **一致**指布局、控件、反馈与交互规则与偏光镜相同；**主色按仪器区分**，沿用 `src/data/instruments.ts` 的主题色：偏光镜紫 `#7c3aed`、折射仪琥珀 `#e8a93a`、分光镜天蓝 `#0ea5e9`。琥珀与天蓝作白字按钮底色对比度不足，按钮与文字用同色系加深一档。
- 偏光镜现有页面不重做，作为参照；可抽出的部件抽成共用后，偏光镜再逐步改用。
- 每阶段本机提交、跑全量回归、截图核对桌面与 390 px 手机；不推送、不发布。

## 三、分阶段

### 阶段 1 · 课程外壳对齐偏光镜（折射仪、棱镜式、光栅式三门课同时受益）

1. 共用设计变量 `instrument-ui.css`：中性色取偏光镜的值，主色按 `data-instrument` 切换；按钮（普通 / 主要 / 安静）、按下态、焦点环、反馈色（完成绿、提示琥珀、说明蓝、错误红、「为什么」主题色）、减少动效。
2. 课程条改为偏光镜结构：步骤条 + 讲师/学员切换 + 退出课程；任务行含「n / N」、任务说明、完成后的「为什么」、本步完成清单、上一步 / 下一步 / 跳过。右侧面板只放本步操作与观察。
3. 步骤锁定统一为「只能去已到达的最远一步」；地址 `?step=` 直达（直达中间步骤记为跳步，与偏光镜一致）。
4. 共用滑杆 `RangeControl`：标签、数值与单位读数、两端刻度、`aria-valuetext`。
5. 问答改为偏光镜式：选择 → 提交 → 逐项 ✓ / ✗ 与反馈；答对后锁定。
6. 完成页：总用时与各步用时（只显示、不保存）、再学一遍、进入自由探索。

### 阶段 2 · 观察区放进三维区，手机布局

- 光谱条、折射仪读数窗作为浮层停靠在三维区内（同偏光镜目镜视场），手机上缩小但保持可见；拖滑杆时能同时看到模型与观察结果。
- 手机三维区高度改为与偏光镜一致（约 59dvh），本步操作紧接其下。

### 阶段 3 · 工作台练习页与自由探索页

- 工作台练习页改用共用页眉、设计变量、`RangeControl`、原地重新载入。
- 自由探索页（折射仪、两种分光镜）课程入口与偏光镜一致：讲师演示为主要按钮。

### 阶段 4 · 三维引导与直接操作

- 「认识部件」步骤加部件编号热点与「点这里」指引气泡（学员模式）。
- 工作台：在三维中直接拖动灯头横移、棱镜式狭缝调节环与目镜套筒（与滑杆同步）。
- 三维载入失败时静态图 + 原地重新载入，不整页刷新。

### 阶段 5 · 投屏与可达性收尾

- 课程投屏模式（全屏、隐藏页眉、Esc 退出、焦点恢复）。
- 相机过渡、自动转动遵守减少动效；手机默认流畅画质；视图按钮 `aria-pressed`。

## 四、执行记录

### 2026-10-10 · 阶段 1 · 课程外壳对齐偏光镜（Claude）

折射仪基础读数课、棱镜式与光栅式分光镜观察课共用的课程外壳改为偏光镜结构，三门课同时生效。

- 新增 `src/styles/instrument-ui.css`：中性色、字体、按钮、焦点环、反馈色取偏光镜的值，主色按 `data-instrument` 切换（折射仪琥珀、分光镜天蓝；按钮用加深一档）；减少动效。`course-shell.css` 全部改用这些变量。
- 课程条：步骤（完成显示绿色 ✓）+ 讲师 / 学员切换 + 退出课程；任务行含「n / N」、任务、完成后的「为什么」、本步完成清单、上一步 / 下一步 / 跳过。右侧面板只放本步操作与观察。手机上只有当前步骤显示名称，其他步骤以读屏标签给出全名。
- 每步的「为什么」与完成清单写在各课程的领域文件中（`courseChecklist`），与完成条件使用同一组判断。
- 步骤锁定统一为「只能回到已到达过的最远一步」（原为仅学员锁定）；`?step=` 直达，直达中间步骤记为跳步。
- 课程内切换讲师 / 学员不再重新挂载、进度保留；本轮用过讲师演示就不写入学习记录。
- 共用滑杆 `RangeControl`：标签、数值与单位读数、两端刻度、读屏文字。分光镜的狭缝读数取模型刃口实测间距。
- 问答改为选择 → 提交 → 逐项 ✓ / ✗；答错不直接给出正确答案，答对后锁定。
- 完成卡片覆盖在三维区与面板之上：总用时与各步用时（只显示、不保存）、保存状态、重试、再学一遍、进入自由探索。
- 测试相应调整：下一步、跳过、完成、退出改用 testid；问答先选后提交；讲师「自由跳转」改为用跳过前进、步骤条回看已到达的步骤，或用 `?step=` 直达。

### 2026-10-10 · 阶段 2 · 观察窗进三维区，手机吸附（Claude）

- 共用 `CourseDock`：观察窗停靠在三维区内（同偏光镜目镜视场）。折射仪读数窗为右上角圆形视场（手机移到右下角，150 px）；分光镜光谱条停靠在三维区底部，「标记吸收特征」直接在停靠的光谱条上点选。停靠窗标题已写明刻度，不再重复轴下说明。
- 右侧面板只留本步操作；折射仪的接触恢复提示改为琥珀色提示框。
- 窄屏（≤ 920 px）三维区吸附在顶部（`position: sticky`），手机高 46dvh：滚到滑杆、按钮时模型与观察结果保持可见。这一点偏光镜手机端也没有做到，以后偏光镜改用共用外壳时一并获得。
- 新增浏览器用例：手机上拖狭缝滑杆时三维区在顶部、光谱条在屏幕内且随设置变化；折射仪窄屏滚动后目镜观察仍在屏幕内。
