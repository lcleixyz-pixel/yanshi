## 一、现状问题（盘点）

| 仪器 | 现有入口 |
|---|---|
| 偏光镜 | 3D 探索（含 5 讲 + 引导课程，同页）、2D 演示、检测 |
| 折射仪 | 3D 探索、基础读数课（同路由不同参数）、2D 演示、检测 |
| 分光镜 | 棱镜 3D 探索、光栅 3D 探索、棱镜课、光栅课、照明夹样练习、2D 演示、检测（7 个） |

**画面**：自由探索铺满编号圈；课程每步把任务、清单、按钮、滑杆、说明、问答一起放出来，文字多于操作。

**做法**：此前按单项需求逐个打补丁，没有先定整体信息结构。

## 二、PhET 风格的含义（本项目采用的部分）

参照科罗拉多大学 PhET 互动仿真（phet.colorado.edu）的通行做法：

1. **一台仪器 = 一个仿真**，打开先看到几个"屏幕"图标，屏幕之间用底部导航栏切换。
2. **操作区为主**：模型占画面大部分，控制面板贴边、成组、可折叠；文字短，多用图标和直接拖动。
3. **隐性引导**：不靠逐条指令，而靠"能拖的东西看起来能拖"、合理的初始状态、即时可见的结果引导探究；对错判断放在专门的挑战屏幕。
4. **统一控件**：右下角橙色"全部重置"；"显示 / 隐藏"用复选框（显示光路、显示名称、显示数值）；读数放在可折叠的读数框里；工具（样品、接触液、镊子）从工具箱拖入。
5. **教学材料与仿真分开**：讲师用的引导任务、讲解要点不占据仿真画面。

## 三、目标结构

### 1. 首页：仪器仿真卡片

```
首页
├─ 折射仪   ─┐
├─ 偏光镜   ─┤ 每张卡 = 一个仿真，点开进入「认识」屏幕
├─ 分光镜   ─┤
├─ 显微镜   ─┘（目前只有「认识」屏幕）
├─ 综合检测（未知样品 → 命名）
└─ 学习进度
```

知识库保留为阅读资料，每台仪器页顶部只放一个主按钮「打开仿真」。

### 2. 每个仿真三块屏幕

| 屏幕 | 作用 | 由现有内容合并 |
|---|---|---|
| **认识** | 结构与光路：拆解、透视、单色光路、部件名称 | 各 3D 自由探索页；偏光镜「认识部件 / 光路 / 原理」讲；分光镜棱镜、光栅两台用屏内切换 |
| **实验** | 真实操作：放样、照明、调节、观察，可换样品、换方法 | 偏光镜「样品 / 干涉图」讲；折射仪课程的操作部分；分光镜照明夹样工作台（棱镜 / 光栅切换） |
| **挑战** | 抽未知样品独立检测并记录，结果进入综合检测与命名 | 现检测流程中该仪器的一步 |

2D 演示收为「设备较旧时使用」的小链接，不再与 3D 并列。

### 3. 引导课程的去处：可选「引导任务」

现有四门课的步骤、完成条件、学习记录规则都保留，但不再占满画面：
- 在「认识」「实验」屏幕右上角有「引导任务」按钮，打开后是一张可收起的小任务卡（本步一句话 + 完成勾选），模型和控件照常可用。
- 学员完成全部任务仍按现规则写学习记录；讲师演示不写。
- 问答题移到任务卡末尾的「检查一下」，不再插在操作面板中间。

### 4. 画面规范（统一用于所有仿真）

```
┌──────────────────────────────────────────────────────┐
│ 仿真名                                    引导任务 ▸   │
│ ┌────────────────────────────────┐ ┌──────────────┐ │
│ │                                │ │ 控制面板 A   │ │
│ │          操作区（模型）         │ │ （可折叠）   │ │
│ │                                │ ├──────────────┤ │
│ │   ┌ 目镜视场 ▾ ┐               │ │ 控制面板 B   │ │
│ │   └────────────┘               │ └──────────────┘ │
│ │ [工具箱：样品 / 接触液 / 镊子]  │  ☐显示光路       │
│ └────────────────────────────────┘  ☐显示名称  (↺) │
│ ── 底部导航：  [认识]  [实验]  [挑战]       首页 ── │
└──────────────────────────────────────────────────────┘
```

- **部件名称**：默认不显示；勾「显示名称」时用短文字标签（PhET 用名称而非编号）；点部件只高亮该部件并显示其名称。取代现在满屏的编号圈。
- **读数与观察**：目镜视场、光谱条、折射率读数都是操作区内可折叠的读数框，可拖到不挡模型的位置。
- **颜色**：中性底色统一；每台仪器保留一个主色用于导航高亮和主按钮（与现设计变量一致），全部重置固定橙色。
- **手机**：竖屏时操作区在上、面板改为底部抽屉；横屏与平板同桌面布局。

## 六、Codex 评审采纳（2026-10-11）

Claude 已对照代码核实以下事实：检测中开始新样品会清空原记录（`detectionStore.startSession`）；综合检测中折射仪仍用 2D（`DetectionWorkflowPage`）；折射仪 3D 课只覆盖固定尖晶石（`refractometerCourse.COURSE_SAMPLE`）；分光镜工作台已有标线、标带、「未见明显特征」与核对保存流程。六项全部采纳，作为实现约束：

1. **挑战与综合检测的关系**：从综合检测进入时，各仪器「挑战」屏共用同一颗未知样品与同一份检测记录，完成后回到综合检测命名；从仿真内直接打开「挑战」是独立练习，另记练习结果，不并入综合检测，也不清空正在进行的综合检测。
2. **实验屏保留记录流程**：可展开的「记录观察」：标线、标带、未见明显特征、补充说明 → 核对保存 → 保存后才开放「对照资料」。保留既有规则：两机型共用 nm 数据、光栅式狭缝与焦距固定、反射法只练布置（谱图待核，不计有效观察）、未核定谱图不能记为未见吸收。
3. **跨屏、任务与重置**：收起任务卡只隐藏卡片；在「认识 / 实验」之间切换保留本轮任务进度、跳步与讲师使用记录。橙色「全部重置」只恢复当前屏场景；「重新开始任务」是任务卡里的单独操作；已写入的学习记录与检测记录都不受影响。
4. **2D 能力不降级**：现有检测观察组件（含折射仪 2D 全样品读数）先原样放入统一外壳；「实验屏可换全部样品的 3D 版本」另列扩展范围，未完成前不撤下 2D。
5. **逐台迁移重定向**：阶段 1 只建新外壳和新地址，不重定向旧地址；每台仪器迁完并通过回归后，再把它的旧入口重定向，并保留机型、样品、观察方法、学员 / 讲师、步骤等参数。
6. **手机与非拖动操作**：手机上任务卡收为顶部一行「引导任务 3/6 ▸」，点开为底部抽屉；记录观察同为底部抽屉；底栏保留「首页」。工具箱支持「点选工具 → 点放置位」，所有拖动调节都保留滑杆或按钮（WCAG 2.2 · 2.5.7 拖动替代）。

**专业表达**：折射仪显示 RI、临界角的框称「示例参数 · 原理计算」，与显示明暗边界和刻度的「目镜视场」分开；分光镜狭缝、调焦未经实物标定，正式界面用相对刻度（0–10），不显示毫米数。

**阶段 0 补充样稿**：手机任务与记录展开；光栅式与反射待核；挑战接续同一未知样品。
