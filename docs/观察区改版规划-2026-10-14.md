# 观察区改版规划（2026-10-14）

> 依据：[偏光镜三版本教学体验对比](偏光镜三版本教学体验对比-2026-10-14.md)（本仓库）、Codex 只读审查《当前 3D 与经典 2D 学习、练习页面对照》（`~/.codex/visualizations/2026/10/13/…/2d-3d-audit-2026-10-14/体验对照.md`，本仓库外），以及 2026-10-14 会话中 Claude 对三台仪器 2D／仿真的实测（第一屏可操作控件 2D 7–11 个、仿真 17–34 个；分光镜谱条 2D 552×189、仿真 358×99）。
> 状态：规划稿，未改应用代码。用户确认第 6 节的选择后再实施。

## 1. 结论

**问题不在「2D 还是 3D」，而在观察结果有没有成为界面主角、操作离结果有多远、提示和答案在什么时候出现。**

- 用户找回的偏光镜旧版 `67b3f08`（2026-10-07）是 3D 的，学员使用较满意，唯一明确要求是优化二轴晶干涉图。它证明三维仪器可以和集中的观察教学共存。
- 现行仿真（`340ea32` 起）的统一入口、三屏、挑战、学习记录与换屏保留场景都值得保留；退步集中在**实验屏的观察区**：目镜与预测、解释挤在左下小卡里，操作在另一侧的长面板里。
- 经典 2D 的长处是**直接操作提示**（仪器上只亮当前一步的热点、写明动作）和**局部放大**（正在调的部件占满画面，旁边小图标出它在整机上的位置）；短处是较早显示参考答案，适合带讲解入门，不宜直接当无答案练习。

## 2. 保留与吸收

| 来源 | 保留／吸收 | 不照搬 |
|---|---|---|
| 旧版 `67b3f08` | 学员观察时的集中工作区：大目镜（220–320 px）与预测卡并排放在展台一侧，仪器右移让位，两侧面板收起；完成短提示；当前部件说明在展台内 | 整页滚动版式；720 px 高度下底部操作需滚动的问题 |

## 3. 工作包

### P0　修复偏光镜观察框重叠（确定的缺陷，先做）

- 原因：迁移时把观察框里的目镜圆环限定为 120–168 px，目镜画布实际显示约 240 px，溢出约 99 px，压住预测按钮与解释（两份审查都实测到）。由 Claude 在阶段 3b 引入。
- 做法：目镜尺寸与所在列一致；预测、观察、解释三段在目镜旁或下方排开，互不覆盖；挑战台同样检查。
- 验收：1280×720、1440×900、390×844 三种视口下完成预测→转一周→揭晓，目镜全域与按钮文字同时可辨；新增浏览器断言「目镜画布不超出所在列、与按钮不相交」。

### P1a　偏光镜实验屏「观察模式」（以旧版学员工作区为参照）

- 进入样品观察（学员引导中，或用户点「放大观察」）时：目镜放大到 220–320 px，与「预测 → 观察 → 解释」卡并排占展台左半；仪器右移让位（沿用旧版的 `viewShift` 0.2）；右侧控制面板收为抽屉，任务卡收为顶部一行。
- 退出观察模式回到现行布局，场景、覆盖率与任务进度不变。
- 旋转控制保留三条路：直接拖物台环、「自动转一周」、键盘可操作的滑杆。
- 短屏（720 px 高）不需滚动即可完成一次观察；手机保持现行「上任务、下读数」的布局。
- 验收：学员能指出当前操作部件、找到下一步、边转边看；课程、记录与挑战能力不丢；现有 `sim-polariscope-*` 用例全部通过。

### P1b　偏光镜认识屏补回旧版课程线索（较小）

- 每完成一项清单在展台上方给 2 秒短提示；当前部件的名称与一句说明显示在展台内（旧版学员模式的做法），而不只在右侧面板。

### P1c　二轴晶干涉图专项（与 P1a 并行，需专业核验）

按对比文档第 4 节，分开做：

1. 先修现行版文字压图（属于 P0 同类布局问题）。
2. 增加「固定角域」观察与现有「扩大角域原理图」并列可选，页面标注区分；现行规则让不同 2V 的光轴出露点都落在约 0.77 倍视场半径，削弱了 2V 差异。
3. 固定样品、厚度、照明与角域，连续检查 0°、22.5°、45°、67.5°、90° 的开合；固定角域下改变 2V，检查光轴位置与是否出视场；分别检查单光轴、锐角等分线与一般取向（取向不合适时允许黑带部分可见或移出）；检查黑带曲率与色环可辨性。
4. 输出一份对照截图组与核验表，交由用户或指定的专业人员判定；判定前不改算法核心，不以生成图代替计算图或实测图。

### P2　推广到折射仪、分光镜（P1a 经确认后再做）

- 折射仪实验屏：右侧约 10 个文字按钮改为**仪器上的动作热点**（开关、油瓶、测台、目镜），只亮当前一步、写明动作；面板只留样品、视角与更多。目镜读数放大为观察主区；认识屏的光路计算卡在「认识部件」步收起，到光路步再展开。
- 分光镜实验屏：谱条放大并与狭缝、焦距、亮度控件放在一起；灯头细调、观察方式等收入「更多」。
- 两台仪器的观察模式沿用 P1a 的外壳能力，不各写一套。

### P2　讲解与练习的答案时机

- 「讲解」（讲师演示、2D 学习模式）可以提前显示参考值与解释；「练习」（学员引导、挑战）坚持先观察与记录、后揭示。
- 2D 学习页在页内明确标注为「带讲解的入门」；是否在首页或仿真认识屏给它一个入口，见第 6 节第 2 条。

### P3　真实学员对照试用（需用户安排）

- 同一任务、交替版本顺序（例如旧版观察区样稿与现行版各一组），记录是否需要提示、误操作次数、能否说明依据、任务用时。
- 至少一台真实手机、一台平板、一次投屏；可合并入阶段 5 的课堂试用（`docs/偏光镜课堂试用观察表.md`）。

## 4. 顺序与确认点

1. **P0**：小而确定，修完即提交。
2. **P1a + P1c 第 1 步**：做偏光镜观察模式，本机提交后由用户（最好带一两位学员）确认，**确认前不推广**。
3. **P1c 第 2–4 步**：交出二轴晶对照截图组与核验表，等专业判定。
4. **P2**：按偏光镜确认后的样式改折射仪、分光镜。
5. **P3**：试用结果回写本文与对比文档。

每步本机提交、全量回归、截图核对；不推送、不发布。

## 5. 不做的事

- 不整仓回退到 `67b3f08`：挑战、记录、检测写回与换屏保留场景都在它之后才有。
- 不为恢复布局改动学习记录、检测与计分规则。
- 不在专业核验前替换干涉图算法核心，也不用生成图冒充实测图。

## 6. 需要用户决定

1. **观察模式何时出现**：只在学员引导时自动进入；还是所有人进入样品观察都默认放大、可退出？（建议后者，讲师投屏同样受益。）
2. **2D 学习页的位置**：继续只作备用入口；还是在首页卡片或仿真认识屏加「带讲解的入门（2D）」？
3. **二轴晶的专业判定**：由谁核对对照截图组（用户本人、讲师，或另请）？
4. **P0 是否直接修**：属于已确认缺陷，建议不等其余决定先修。
