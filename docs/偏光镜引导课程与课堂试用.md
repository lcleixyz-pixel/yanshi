# 偏光镜基础引导课程与课堂试用

2026-10-07。本地开发成果，分支 `feat/polariscope-guided-course`，未部署、未推送、未产生费用。承接 [样品观察、干涉图与物理视场](偏光镜3D样品观察与干涉图.md)。

本轮只做「整理成 5–8 分钟引导课程」与「课堂试用」两项。「统一新旧页面教学规则」未做：旧互动页 `/demo/polariscope`、检测页和结果解释的文案与判定没有改动。

## 课程范围

入口：`/explore/polariscope` 标题区的「引导课程 · 约 8 分钟」，或直接打开 `/explore/polariscope?course=basic`。不带 `course` 参数时页面仍是原来的自由探索，五个分节和控件不变。

| 步骤 | 场景 | 完成条件 | 预计 |
| --- | --- | --- | --- |
| 1 认识部件 | 结构 | 点选下偏光片（04）、载物台（05）、上偏光片（06） | 1 分 |
| 2 跟随光路 | 光路 | 走到第 5 / 5 步 | 1 分 |
| 3 空载调正 | 偏振原理 · 空载 | 看到 0° 平行最亮，并转到 90° 正交、透过率 0 | 1 分 |
| 4 放样旋转 | 样品观察 | 尖晶石、碧玺、翡翠各做一次「预测 → 转满一周 → 揭晓」：始终暗 / 四明四暗 / 始终亮 | 2 分 |
| 5 换方向复核 | 样品观察 | 同一块碧玺先沿光轴转一周（全暗），之后换方向再转一周（四明四暗）；顺序必须先沿光轴、后换向 | 1.5 分 |
| 6 解释 | 问答 | 三题全部答对：为什么调正交、为什么换方向、哪些情况不能下结论（多选） | 1 分 |

- 基础课程只覆盖典型反应。课程完成页提供进阶入口：水晶旋光（黄晶沿光轴）、巴西律双晶（紫晶）、异常双折射与平行复核（石榴石）、锥光干涉图。点击后退出课程，进入自由探索中的对应分节和样品。
- 每步的完成依据都来自页面原有的同一套判定（`judgeObservation`）。课程不另写光学结论，揭晓解释仍是原有文字。
- 「下一步」要求本步完成；「跳过」可用于教师讲解。完成页按步显示用时，跳过的步骤标明「已跳过」。用时只在本页显示，不保存、不计分，不访问已有学习或检测存储。
- 课程进行中隐藏分节切换（标题区标签、投屏的讲解内容下拉、「沿光路继续认识」按钮），避免场景和步骤错位。答题和完成页显示时收起两侧面板，避免作答时误改样品状态。

## 结构讲解优化（2026-10-07，按用户建议）

| 建议 | 处理 | 验证 |
| --- | --- | --- |
| 部件标识位置不准，尤其支架 | 标号锚点从「包围盒中心」改为部件可见表面上的点：沿主视角射向部件取第一个命中点，未命中时取朝向主视角、离中心最近的顶点。支架在清单中指定锚点，落在竖直后壁前侧面。标号沿「模型中心 → 锚点」方向引出，锚点有小圆点和引导线。 | 测试：支架锚点在屏幕上明显位于上偏光片左侧，锚点圆点可见 |
| 堆叠部件聚焦不清晰 | 认识部件时选中一个部件，其余部件淡化到约 14% 不透明度，标号同步变淡；底座与支架为一体外壳，选其一时另一个保留。「单独查看」仍是完全隐藏其余部件。 | 测试：淡化范围、选支架时保留底座、单独查看与清除选择后恢复 |
| 光源离下偏光片太近 | 网页场景把示意光源模块在空心底座内下移 0.17（发光面约从 0.377 降到 0.207，与下偏光片间距约 0.08 → 0.25），模块仍在外壳底面之上。写入 `manifest.json` 的 `internalLight.teachingOffsetNative` 和 `provenance.json`；GLB 未改，重建脚本与 Blender 母版未同步。 | 测试：光源位置 0.1–0.25 之间；光路讲解画面已人工查看 |

其余部件共用的材质会按部件复制一份，避免淡化时互相影响。内部光源在底座内部，外壳不透明时它的锚点圆点会画在底座正面，这是示意位置。回归：单元测试 51/51，浏览器测试全量 163/163，加上新增 3 项。

## 视觉风格统一（2026-10-07，用户选择「统一到项目主风格」）

3D 页原来使用自带的灰绿 / 纸色样式，与知识库、旧互动页、折射仪、分光镜使用的项目统一取值（`tailwind.config`：ink / line / brand 蓝白学术风、偏光镜主题紫 `#7c3aed`、功能色）不一致，文档中也没有记录选用理由。本轮改为项目统一取值，布局与交互不变：

- `polariscope-explore.css` 的根变量改为项目取值，约 140 个写死的颜色按色系映射到这些变量（剩约 50 个，多为同一取值的透明度变体）。中性面板用蓝灰，选中与主操作用主题紫，完成状态用功能绿（与原型图、旧互动页的完成对勾一致），提示框用警告色，教学注释用信息色。
- 场景里的选中光环、引导线、锚点、外壳轮廓线同步改色。四种光路标签的颜色与光束对应，保持原值。
- 页眉改用项目共用的 `Header` 组件（与知识库、检测流程、命名评估、学习进度一致），按钮使用 `btn-ghost`；等宽字体改为项目的 JetBrains Mono。

## 学员自学模式（2026-10-07）

入口：标题区「学员自学」，或课程条右侧的「讲师演示 / 学员自学」切换；地址为 `?course=basic&mode=student`。课程步骤、完成条件和判定与讲师演示共用，不另写一份。

参考了原型图和旧互动页 `/demo/polariscope` 中面向学员的做法：标注写动作、每步一个焦点、仪器定位、观察时目镜视场在中央并说明「眼睛看视场、手转载物台」、实时反馈和完成门槛。在 3D 页中的对应：

| 做法 | 实现 |
| --- | --- |
| 两侧面板收起 | 部件目录与右侧说明在 ≥681 px 宽度下隐藏；本步需要的控件集中在展台底部操作条（复用投屏控件） |
| 动作提示指向部件 | 场景内气泡经虚线引导线指向部件表面锚点，锚点有脉动圆点，环形部件同时显示选中光环。规则见 `studentCoach`：每步只指向一个部件；未通电先指向电源按钮，未正交先指向上偏光片 |
| 说明不离开展台 | 部件、光路、偏振原理说明使用投屏模式的说明卡，显示在展台左上 |
| 认识部件时不丢失全局 | 学员模式选中部件只淡化其余部件，镜头不推近，下一个要点的部件仍在画面内 |
| 目镜视场在前 | 放样旋转、换方向复核时，目镜视场放大到展台左侧，仪器整体右移（相机视图偏移，拾取与标号随之一致）作为定位参照 |
| 预测 → 观察 → 解释 | 视场旁的卡片依次给出预测选项（三种典型反应 + 「不确定，直接看」）、已转过百分比与当前明暗的实时提示、揭晓解释与「换个方向放置」按钮；未通电或未正交时卡片改为纠正提示和一键纠正按钮 |
| 即时反馈 | 清单项完成时展台顶部显示约 2 秒的完成提示 |

手机宽度（≤680 px）保持原来的上下排列与课程条，只增加动作提示，不移动目镜视场。

验证：新增 `tests/polariscope3d-student.spec.ts` 7 项（面板收起与部件提示、空载调正提示、目镜在前的预测与揭晓、未正交时就地纠正、换方向复核、切回讲师演示、390 px）。全量浏览器测试 **173/173**，单元测试 51/51；Safari 引导课程走查（讲师演示）在换色后重跑 21 项通过。学员模式本轮只在 Chrome 中验证，Safari 未单独走查。

已知问题：空载调正一步中，动作提示气泡会部分遮住场景标签「视场：从上往下看」；气泡目前只避开画面边缘，不避让其他标签。学员模式尚未经过真人试用，试用观察表同样适用（把入口改为 `?course=basic&mode=student`）。
