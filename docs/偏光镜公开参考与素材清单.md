# 偏光镜：原项目资料与公开参考

核查日期：2026-10-05。用户先指定优先搜集公开资料，随后明确要求参考原演示项目中的仪器形态与资料。当前不要求完整拍摄手头仪器。

## 当前采用的做法

外形以原项目 `偏光镜/偏光镜_产品图.png` 为基准：厚白底座、连续白色折板支架、向前伸出的圆头顶托、上下黑色旋转环和左侧干涉球。原演示的 `public/assets/instruments/polariscope.png` 与该原图内容一致。v0.3 的双立柱布局及 v0.3.1 的加厚箱体不再作为最终外形方向；v0.4 回到原项目参考形态。所有尺寸仍是暂定参考比例，尚未实测。

机构与用语同时核对项目 `偏光镜/偏光镜.pdf` 第 10–12 页：图 2-2-6、2-2-10 展示台式机外形，图 2-2-9 标注可转物台与固定下偏光片。正文把载物台和下偏光片并写，不能据此添加机械联动；当前沿用原演示已有的独立物台操作。原 PNG 前方橙色面板、教材照片的顶面开关、现有数据的“背面开关”并不一致，因此前橙色面板只作为照明示意窗，不能标成已经证实的实物电源开关；网页电源仍通过明确的操作控件控制。

公开图片按文件逐项核查作者与许可。许可明确的原件保留来源、许可链接和哈希；网上厂商图仍仅保留参考链接。项目原图依据用户明确指示用于本地形态参考，外部作者与再利用许可尚未核实，不将其标注为 CC0 或原创设计。生成网格不嵌入原图、商标或图像纹理。本记录说明资料的实际使用方式，不能保证覆盖所有第三方权利。

## 图片收集与观察证据

完整的逐文件清单、作者、许可、来源和原件保存在 `gem-lab/assets-source/polariscope/references/`。仅保留已核许可的原始文件；不将网上图样默认为实测数据，也不将偏振应力照片解释为宝石鉴定结果。

当前 `observations.json` 仍为 pending。公开的演示 GIF 可以帮助理解现象，但若缺少完整旋转角度、取向、时间点或照明条件，就不能填补这些字段、解除实训完成条件。

需要用户配合的范围已缩小：先审阅通用结构与教学用语；若要完成特定样品的一周观察闭环，再补“仅视场与角度参照”的短视频和样品取向说明，无需先拍摄整台品牌仪器。

## 整周观察素材的后续线索

补充定向检索尚未找到可直接纳入本页严格实训的完整宝石角度序列。[rockPTX](https://www.rockptx.com/video-atlas-of-minerals-in-thin-section/) 提供真正 360° 矿物薄片录像，但页面标明版权保留，只作为外链；[UAB Minescope](https://ddd.uab.cat/collection/minescope) 还需逐记录核查许可、角度与取向。当前未将这些媒体下载进项目。
