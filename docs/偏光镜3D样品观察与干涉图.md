## 物理模型（`src/domain/polarizedLight.ts`）

- 任意检偏角的线性延迟片透射（Bloss 通式）：`I = cos²A − sin2ψ·sin2(ψ−A)·sin²(πΓ/λ)`；正交时为 `sin²2ψ·sin²(πΓ/λ)`。空载退化为马吕斯定律。
- 干涉色：400–700 nm 光谱 × CIE 1931 配色函数（Wyman–Sloan–Shirley 2013 解析式）× 6500 K 光源，白光归一；查找表用 1 nm 采样，按像素光程差足迹做区间平均以避免高阶色环混叠；约 20 µm 以上按高级白处理。
- 一轴晶：`Δn(θ) ≈ (nₑ−nₒ)·sin²θ`，e 光振动方向为光轴在波面上的投影。
- 二轴晶：`Δn ≈ (nγ−nα)·sinθ₁·sinθ₂`，振动方向按 Biot–Fresnel 规则取两光轴迹线的角平分线。
- 水晶旋光：线性延迟与圆延迟合成椭圆延迟器（Jones 计算），旋光率 `ρ(λ) = 7.27/(λ²−0.0127) °/mm`（λ 以 µm 计，589 nm 时约 21.7 °/mm）。巴西律双晶示意为左右旋两层叠加。
- 正光视场（`src/domain/eyepieceField.ts`）：单晶各刻面消光方向一致、路径长度不同；集合体为大量随机取向晶粒且光近于退偏；均质体可叠加平滑应变场（异常双折射）；不透明样品无透射光。
- 显示曝光 1.7（模拟人眼对暗视场的适应），只影响画面，不影响曲线与判定数值。

由此自然得到、并有单元测试覆盖的现象：

| 现象 | 结果 |
| --- | --- |
| 一轴晶光轴居中 | 黑十字沿起偏/检偏方向，转动物台十字不动；光轴偏斜时十字平移、两臂不旋转。 |
| 水晶 | 十字到不了中心，中心为彩色圆斑（牛眼）；中心颜色随检偏器角度改变。原实现把中心压暗，方向相反。 |
| 二轴晶锐角等分线图 | 消光位合成十字，转 45° 分成两条双曲线、黑带移到光轴出露点。原实现写成「0° 张开、45° 合并」，顺序相反。 |
| 二轴晶单光轴图 | 一条穿过中心的黑带，随物台转动。 |
| 正光 | 尖晶石全暗；碧玺一周恰好四次极暗；翡翠始终亮且亮度几乎不变；沿光轴放置的碧玺也全暗；绿松石不透光。 |
| GIA 平行复核 | 转到最亮位再把检偏器转平行：应变（ADR）明显变亮，真正双折射不变亮。 |

石榴石、琥珀按样品库「常见异常消光」默认带应变，可用滑块关闭。样品体色、2V（橄榄石 86°、托帕石 56°、坦桑石 40°、月光石 60°、葡萄石 66°）与厚度是示意取值。

## 教学设计依据

- 预测—观察—解释（POE）：先选预测，转满一周后才揭晓；曲线是学生自己的观察记录，揭晓后叠加理论曲线。
- 多表征联动：三维仪器、目镜视场、明暗曲线、说明文字同一状态驱动；标签贴近部件。
- 宝石学规范陷阱直接做成操作：沿光轴放置会全暗（需换方向复查）；ADR 平行复核；不透明样品不适用。
- 调研来源见本轮调研记录，主要参考 GIA 偏光镜用户指南、MSA《Quartz: a Bull's Eye on Optical Activity》、LibreTexts 干涉图章节、Sørensen 2013 Michel-Lévy 色图、PhET 隐性脚手架研究（arXiv:1306.6544）、Mayer 多媒体学习原则。

## 独立复核与修正

另起一个只读复核代理检查物理与代码：Jones 矩阵与直接复数矩阵指数对比（2000 组随机参数，误差 1e-14 量级）、归一化、转向约定、干涉球姿态换算与资源释放均核实无误。其指出并已修正：

1. 平行复核对正交下本来就暗的样品（尖晶石、沿光轴放置）会误判为「异常双折射」——改为先判断是否存在亮位，沿光轴时提示先换方向。
2. 高刷新率屏幕（90/120 Hz）上「自动转动一周」转不满、解释不出现——改为按累计转角精确终止。
3. 可以先转后预测、关灯或非正交时也计入观察——现在只有已预测、通电、正交时才记录。
4. 平行复核会把已揭晓的解释收回——揭晓状态单独保存。
5. 水晶干涉图逐帧约 141 ms——改为闭式解与预计算旋光率；光轴竖直时转动物台不重算（图形本身旋转对称）。
6. 2V 较大的二轴晶锐角等分线图黑带落在视场外——该视图改用宽视场，并在说明中注明。
7. 换样品时三维样品朝向可能与目镜不一致——样品在物台局部坐标中不再附加旋转。
8. 半透明均质体（欧泊）视场偏灰——揭晓时补充说明散射造成的暗灰。

上述 1、3、4、6 及「光轴偏斜时十字两臂保持横竖」均已补测试。葡萄石在样品库中按单晶记录，实际常见集合体，建议复核样品数据。

## Codex 复审后的修正（2026-10-06）

1. 水晶沿光轴：不再按「全暗」处理。正光视场与干涉图共用旋光计算，水晶沿光轴呈不随转动改变的颜色，揭晓说明为「不暗也不闪」。
2. 取向统一：`alongOpticAxis` 与 `conoscopeView` 合并为一个 `orientation`（一般方向 / 光轴直立 / 光轴偏斜 / 锐角等分线），正光与锥光用同一个晶体模型，放上、取下干涉球前后方向不变；干涉图新增「一般方向」，展示找不到光轴出露点时的样子。
3. 「恢复初始状态」清空预测、记录与揭晓；单次跳变超过 15°（End、PageUp、预设按钮）只记录落点，必须连续转满一周。
4. 投屏模式增加预测下拉与「教师演示（不预测）」，面板中同样提供「教师演示」。

5. 用户复现：干涉图中开启黄水晶巴西律双晶后进入样品观察并沿光轴放置，画面全暗却判为「不暗也不闪」。原因是结论按固定规则给出、没有跟随双晶条件。现在非均质单晶的结论直接由画面所用的正交明暗曲线判定（与学生看到的一致），并新增「双晶抵消旋光、沿光轴全暗」的解释；样品观察中也显示双晶开关，跨讲状态一目了然。

测试：单元 36/36；浏览器 68/68（lesson 规格 12 项，其余 56 项回归）。

## 整体验收（2026-10-06）后的修正

独立整体验收（`/tmp/polariscope-overall-2026-10-06/整体验收结论.md`）结论为「阶段成果可保留，完整教学验收暂不通过」，指出：

1. **P1 非水晶沿光轴被解释成旋光**（红宝石、蓝宝石、祖母绿、月光石、葡萄石）：上一轮把结论改为「看曲线」时，没有扣除半透明散射造成的恒定灰底（0.07 越过了 0.06 阈值）。
2. **P1 无应变样品被平行复核判为 ADR**（欧泊、应变为 0 的琥珀）：同一散射灰底在平行时「变亮」被误读为应变。
3. **P2 重建脚本未回写**：`repair_candidate.py` 仍会生成「折板支架」和可拆位移。

修正：判定移入 `domain/eyepieceField.ts` 的 `judgeObservation` 与 `parallelCheck`——只用随偏振变化的光（扣除散射退偏），并加材料机理约束（旋光只属于水晶，ADR 只属于设置了应变的均质体）；关灯时平行复核不可用。重建脚本的标签、拆解位移、`integralShell`、`mechanics` 已与网页清单一致（静态比对通过，未重新运行 Blender，GLB 哈希不变）；repair-v2 源清单同步。Playwright 改为只收集 `*.spec.ts`，不再误收 node:test 单元文件。

验证：单元 38/38；Playwright 全量 154/154（6 个规格文件，含 84 项原有样品矩阵）。新增判定矩阵测试：28 种样品 × 全部取向 × 双晶 × 应变 × 1/2.5/5 mm 厚度，全部符合机理；并补两条验收复现的浏览器测试。厚度低于约 1 mm 的水晶旋光很弱，沿光轴按「近于全暗」判定，这与物理一致。

验收中「直接拖环」因输入工具没有产生连续移动事件未能验证；仓库中的原生场景规格已用真实射线命中拖动检查角度变化。

## 宝石学审查（2026-10-06）后的修正

审查报告：`/tmp/polariscope-gemology-audit-2026-10-06/宝石学审查结论.md`。逐条核对源码与所引 GIA 资料后全部采纳：

1. **葡萄石**：样品图本身是弧面纤维状标本，原资料却按刻面二轴单晶建模。样品库改为纤维集合体（弧面、半透明、无单一双折射率），偏光镜始终亮、无干涉图；提示注明「矿物为二轴晶，不能直接当作整块标本的光性」。新旧页面与折射仪共用此资料，一并生效。
2. **ADR 判读边界**：新页「不规则明暗」限定为本例特征，四明四暗的解释补充「ADR 也可能出现规则明暗交替，需平行复核并结合折射仪」；旧页的观察要点、全暗、四明四暗三处同步补上方向复查与平行复核条件。
3. **旧页牛眼**：普通一轴晶改称「黑十字加同心色环」，单独说明水晶牛眼由旋光所致、受取向/旋向/双晶影响；提示语改为「牛眼（旋光所致）→ 常见于水晶」，不写成只有水晶才有。
4. **干涉球作用**：知识库改为「放在样品上方、靠近或轻触观察区域；光自下而上先穿过样品再进入干涉球」，新页放球前的说明同步。
5. **干涉图说明跟随状态**：巴西律双晶示意时说明中心消光并注明理想双层模型的限定；一般方向按视场内实际的光轴出露点数目给出两种说明（橄榄石有一条落在视场边缘）；大 2V 宽视场标为「扩大角域原理图」，并说明实际干式仪器通常看不全。
6. **共享资料**：月光效应改为正长石与钠长石出溶形成的微细层状交生（非聚片双晶）；珍珠提示改为「不透明，标准透射偏光镜不适用」。

补测试：葡萄石集合体判定、橄榄石一般方向的可见光轴、双晶中心消光（单元）；双晶干涉图文案（浏览器）。验证：单元 39/39，Playwright 全量 155/155。

## Codex 定向修复与复测（2026-10-06）

针对后续验收留下的两项问题，已直接修改并完成本地验证：

1. **干涉图说明条件**：说明接收实际正交／平行状态和可观察条件。平行、斜交时不再套用正交消光解释；等厚左右旋双晶沿轴且平行时说明中心明亮；偏轴时区分光轴出露点与视场中心；关灯优先提示当前暗场不能判断消光。橄榄石一般方向的光轴位置改称“视场内、偏离中心”。光学渲染算法未改。
2. **点测结果核对**：命名结果页把实际测量方法传入 `domain/refractometerAssessment.ts`。点测按单个近似读数与资料范围核对，允许两位小数的半末位舍入误差；不再要求一个点测值同时等于两个主折射率边界。葡萄石正常保存的 1.64 通过，明显错误值 1.75 不通过；刻面法双端容差与超量程规则保留。参考栏明确标为“点测参考”，不把范围解释成可测得的双折射率。未改变计分或样品数据。

验证：`npm run test:unit` **45/45**，`npm run build` 通过。新增 6 项点测校验测试覆盖实际保存链路、舍入边界、刻面严格性、超量程和无读数。干涉图在本机浏览器实测正交、平行、斜交、偏轴、关灯、取下干涉球六种状态，说明均与条件一致。扩展了原有双晶浏览器测试用例，但本轮没有执行 Playwright 全量测试或重新做 Safari、性能与实物验收。

复测截图及页面文字保存在 `/tmp/polariscope-fix-2026-10-06/`；这是临时检查材料。构建仍有既存的 3D 分包大小和 Browserslist 数据更新提示。
