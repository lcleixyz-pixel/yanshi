**可直接复用的现成部件与函数**

- `stateForLesson` / `lessonPatch`（页面内私有，需抽出）：进入某讲时的场景初值。
- `COURSE_SETUP`（页面内私有）：课程六步各自的讲次与场景补丁；`parts` 步 `analyzerAngle: 0`，
  `crossed` 步从 0° 平行开始。
- `useStageRotation` + `rotationCoverage`：转一周的覆盖率（72 格），跳变 > 15° 只记落点。
- 目镜链路：`buildSampleFieldMap → rotationCurve / meanSampleLuminance / judgeObservation / parallelCheck`，
  干涉图为 `renderConoscopicFigure(crystal, …)`，`crystal` 来自 `sampleCrystal(profile, orientation, brazilTwin)`。
- 关键换算：`recording = 样品讲 && 已预测 && 通电 && 正交`；`coverage >= 1` 触发揭晓；
  `crossed = |analyzerDirection % 180 − 90| < 0.5`；`halfWave` 时强制 `analyzerAngle 90 / stageAngle 0`。
