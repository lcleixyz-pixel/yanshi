# 旧技术草模（不用于交付）

此处保留首轮 Three.js 程序草模和独立查看器源码，供技术参考。它不是 Blender 母版，也不是实物测量结果。复制的 Three.js 运行库已归档；安装锁定依赖后，`../generate.mjs` 会重新复制运行库及 MIT 许可证。

`../generate.mjs` 仅在此目录下重建旧草模，不会覆盖应用使用的资产。

`../blender/build_polariscope.py` → 顶层 `polariscope-master.blend` → `polariscope.glb` 是旧 v0.4 制作链。现行教学入口 `/explore/polariscope` 使用 `public/assets/3d/polariscope/structure-v1/repaired.glb`。当前母版和旧版资料的恢复入口见[资产归档与恢复](../../../../docs/资产归档与恢复.md)。
