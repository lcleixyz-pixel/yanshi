## 交付（每台仪器）

```
gem-lab/public/assets/3d/<id>/structure-v1/
  model.glb            网页用；分件节点命名 <Instrument>_<part>
  manifest.json        沿用偏光镜 structure-v1 格式：parts[id,label,node,pivot,rotationAxisLocal,rotatable,explodeOffset,可选 hotspot]、sha256、units、dimensionsCalibrated:false
  provenance.json      参考来源、生成与修整记录、许可与使用边界、Tripo 消耗
  poster.png           加载失败时的回退图
gem-lab/assets-source/<id>/                     （被 git 忽略；大文件放这里）
  references/          参考图原件 + sources.json（URL、作者/厂家、许可或使用说明、获取日期；AI 生成的图片明确标注「AI 生成」及所用提示词）
  tripo-trials/<日期>/ 原始候选、修整母版 .blend、可重复重建脚本、渲染图、检查记录
gem-lab/tools/3d-assets/   新增脚本可以放这里（入库）
docs/新仪器3D资产-制作记录.md   入库：每台仪器的过程、参考来源、校验结果、Tripo 消耗、未解决问题
```

技术要求：

- 部件分件，与上面的部件清单对应；可动部件（狭缝、调焦套筒、遮光盖、变倍 / 调焦旋钮、光阑）的转轴或平移轴写在 manifest 里。
- 网格封闭检查、导出后重新导入检查、glTF Validator 0 错误；玻璃、金属、塑料材质区分清楚。
- 网页 GLB 单个目标 ≤ 10 MB（可以用 meshopt / Draco 压缩，或适度减面；纹理可用 KTX2）。高质量母版另存在 `assets-source`。
- 每台仪器各渲染一张「参考图与模型同角度对照图」和六视图，供用户审阅外观。
- 尺寸为教学示意，`dimensionsCalibrated: false`；不要声称实测。
