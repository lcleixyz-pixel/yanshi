## 复核方法

从 `/knowledge/polariscope#structure` 进入 3D，依次检查整机、100% 拆解、内部光源、关灯、侧面按钮、两个操作环、部件独立查看、复位和投屏退出；随后回到知识库及原互动学习。使用 `?diagnostics=1` 可在开发模式显示性能与场景状态，普通课堂页面隐藏诊断信息。

构建与逻辑检查在 `gem-lab/` 执行 `npm run build`、`npm run test:unit`。适配后的浏览器回归位于 `tests/polariscope3d*.spec.ts`；实际执行与工具限制在本次验证记录中分别说明。

本次接入完成不等于真实样品光学观察验收。将来补齐固定样品、固定取向与角度序列后，再评估 3D 页与现象教学的连接。
