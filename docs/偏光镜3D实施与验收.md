## 已实现

- React 18 + 原生 Three.js，路由和三维渲染按需加载。没有引入 R3F、后端、账号或云服务。
- 结构、拆解、实训三个视图；8 部件目录与热点联动；选中聚焦、隔离、连续拆解和复位。
- 检偏环与物台直接拖动，原生滑块支持键盘；相机操作与教学角度分离。多指事件、残余相机阻尼和固定视角拖环有针对性处理。
- 六个与 Cycles 一致的正交相机预设、自由观察、精细/流畅画质、投屏模式及 Esc 退出。
- 单一 React 状态驱动仪器与读数。仅空载、开灯、组装完整时显示理想相对透光；关灯、拆解、隔离均停止有效观察。
- 实训含空载确认、放样、旋转记录与解释；有空载原理题。真实记录支持照片或视频目标时间回放、样品/取向条件与来源显示。媒体失败、时间越界或记录不足均不能计入完成。
- 当前无合格样品观察数据，示意样品只用于空间关系。不会产生样品光强、鉴定结论或完成结果。
- 加载超时、失败及 WebGL 上下文丢失有模型渲染图回退；重试可重建场景；离开路由停止动画、取消下载并释放 Three/WebGL 资源。
- 页面不访问已有学习/检测存储，不写计分或学习进度。

## 仍需确认

1. **教学结构与用语审阅**：对照原演示仪器图，审阅外形、部件关系和动作是否适合课程。当前不声称特定实物尺寸或隐藏机构已验证。
2. **材质与近景审阅**：对照六个固定视图、GLB 与网页画面；技术自检不等于用户审美验收。
3. **完整样品实训**：需有许可且条件明确的固定样品、固定取向、一周角度与时间记录。公开金红石/方解石 GIF 不具备这些完整条件。本轮暂未找到可直接替代的公开序列。

必要时用户只需补样品视场视频与角度参照、取向和照明说明，不必完整拍摄品牌仪器。300 元仅为云对照规划上限，本轮消费 0 元，未发生充值、上传或 API 生成。

## 复现

应用：在项目根运行 `npm run dev`，打开 `/explore/polariscope`。

母版：见 `gem-lab/tools/3d-assets/blender/README.md`。重建前保存手工调整；脚本按参数更新派生母版与 GLB。

验证：`node gem-lab/tools/3d-assets/verify.mjs`；在 `gem-lab` 运行 `npm run build`、`npm run test:unit`、`npx playwright test tests/polariscope3d.spec.ts tests/polariscope3d-scene.spec.ts`。

网页证据脚本：`capture-browser.mjs` 与 `verify-safari.mjs`，默认连接已启动的 `http://127.0.0.1:5178`。Safari 需要用户允许远程自动化并启动 `safaridriver -p 4445`；脚本不修改浏览器安全选项。参考图库由 `build-reference-gallery.mjs` 从已核许可原件生成并复核哈希。`build-comparison.mjs` 核对 Chrome 证据与 GLB 哈希后生成原图和六视图对照页。
